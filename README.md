# Instructions on new features

UniversalCMD v1.1.0 pre-alpha introduces E2U mode, which stands for Easier 2 Understand, or Easy 2 Use, or Easy 2 Understand... okay let's just call it E2U.

V1.0.3b introduced the `install` command, so using that, you can type `install e2u`, then it should start installing E2U mode.

(Keep in mind the `install` command as a whole requires an internet connection. And also E2U mode replaces UniversalCMD.py, so just run that to enter E2U mode)
